# renderer/core/components/

Plain JS modules. Functions that return or mutate DOM nodes. No shadow DOM.

- `header.js` — grove title, nav, search trigger, theme toggle, language switcher
- `footer.js` — links, license, RSS link
- `sidebar.js` — TOC (single view) or section/tag filters (grid/list)
- `card.js` — post card for grid/collection views
- `search.js` — input + results overlay, IndexedDB query
- `form.js` — declarative fields + submit
