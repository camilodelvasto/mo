# Welcome to Grove

Grove takes your leaf posts and assembles them into a site. Structure comes from your folder hierarchy. Collections let you curate sequences. The build pipeline generates static HTML that works without JavaScript.

## What you get

- Real URLs derived from your content tree
- RSS feeds (XML and JSON)
- Open Graph tags on every page
- Client-side search backed by IndexedDB
- Dark mode with no flash
- Offline support via service worker

## Next steps

Write a post in `posts/`, run `moui serve --shape grove`, and see it rendered.
